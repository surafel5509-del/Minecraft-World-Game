# Production roadmap

The playable foundation demonstrates phases 1–3: OpenGL ES 3, chunked procedural terrain, first-person movement, day/night lighting, block editing, 64 block registry, inventory, and persistence. Next adapters should add texture atlases and mesh occlusion, audio, mobs/pathfinding, multiplayer transport, Play Games/Firebase, and the vehicle/entity systems. Keep all platform services behind interfaces so offline play remains available.
